# Story 5.1: Design System Foundation

**Status:** `Done`
**Epic:** `5: Design System & UI/UX Modernization`

## Story

**As a** Developer/Designer,
**I want** to establish a comprehensive design system,
**so that** we have consistent visual elements throughout the application.

## Acceptance Criteria

1. Criar um sistema de design tokens incluindo:
   - Paleta de cores (primária, secundária, estados, fundos, bordas)
   - Sistema de tipografia responsivo (font-family, tamanhos, pesos, line-heights)
   - Sistema de espaçamento baseado em grid de 8px
   - Sombras e elevações consistentes
   - Sistema de cores com modo escuro/claro nativo
   - Definir animações e transições padrão (duração, easing)
   - Sistema de ícones consistente
   - Princípios de densidade visual (compact, comfortable, spacious)
2. Implementar variáveis CSS globais para todos os tokens
3. Criar componentes base reutilizáveis (botões, inputs, cards, modais)
4. Documentar o design system em um arquivo de referência

## Testing

### Test file location
- `apps/web/app/components/ui/*.test.tsx` - Testes unitários dos componentes
- `apps/web/app/lib/theme.test.ts` - Testes da lógica de tema

### Test standards
- Usar Vitest com describe/it blocks [Source: architecture/test-strategy.md#11]
- Cobertura mínima >80% para componentes base [Source: architecture/test-strategy.md#7]
- Testar todas as variantes e estados dos componentes

### Testing frameworks and patterns to use
- **Unit Tests**: Vitest para componentes React
- **Testing Library**: @testing-library/react para testes de componentes
- Mockar contextos quando necessário

### Specific testing requirements for this story
- Testar todas as variantes de cada componente (primary, secondary, ghost, etc.)
- Testar todos os estados (hover, focus, disabled, loading)
- Testar toggle de tema light/dark
- Validar acessibilidade (ARIA attributes)
- Testar responsividade dos componentes
- Verificar que variáveis CSS são aplicadas corretamente
